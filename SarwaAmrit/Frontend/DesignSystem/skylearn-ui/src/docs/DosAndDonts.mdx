# Do's and Don'ts

## Do

- Use **Atkinson Hyperlegible** for body copy.
- Enforce **56px minimum** tap targets on kid-facing controls.
- Pair every correct/incorrect state with an **icon**, not just color.
- Reserve **confetti** for lesson completion, not routine correct answers.
- Use **sun yellow** only for achievements and rewards — never primary CTAs.
- Offer **Read to me** on every reading passage.

## Don't

- Use harsh red for errors — **coral** is intentional.
- Condescend (**"Oopsie!"**, **"Yay!"**) — specific feedback respects the learner.
- Drop text below **16px** in kid-facing UI.
- Rely on **color alone** to convey meaning.
- Use cartoonish gradients, sticker clutter, or excessive emoji.
- **Autoplay** sound.
- Gate critical controls behind **hover-only** interactions.
