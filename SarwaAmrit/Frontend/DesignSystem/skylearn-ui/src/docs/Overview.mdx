# SkyLearn

Warm, bright design system for **K–8 edtech** — friendly sky blue, sun achievements, leaf progress. Built for **kids** (large tap targets, clear rewards) and **parents/teachers** (readable progress).

## Principles

- **Atkinson Hyperlegible** for body copy (dyslexia-friendly)
- **56px minimum** tap targets on kid-facing controls
- **Coral**, not harsh red, for “try again” states
- **Sun yellow** for rewards only — not primary CTAs
- **Confetti** on lesson completion only
- **Light and dark** appearance (`light` | `dark` | `system`) via `ThemeProvider`

## Packages

```bash
npm install @skylearn/ui
```

```tsx
import '@skylearn/ui/styles.css';
import { ThemeProvider, LessonCard, BigFriendlyButton } from '@skylearn/ui';

// defaultColorScheme: 'light' | 'dark' | 'system'
<ThemeProvider defaultColorScheme="system">…</ThemeProvider>
```
