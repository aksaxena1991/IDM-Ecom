# Accessibility

Accessibility is first-class in SkyLearn, not an afterthought.

## Typography and contrast

- **Atkinson Hyperlegible** for body and instructions (dyslexia-friendly letterforms).
- Minimum **16px** type in kid-facing UI; instructions at **18px+**.
- Contrast targets **WCAG AAA (7:1)** on body text; **AA large (4.5:1)** on display sizes.

## Interaction

- **56px minimum** tap targets on kid-facing controls.
- No hover-only critical actions — touch devices need explicit affordances.
- **No autoplay audio** — every sound requires user intent (e.g. **Read to me**).

## Meaning beyond color

Correct and incorrect states always pair **color + icon + copy** (checkmark / ×, border, message).

## Reading support

- **Read to me** on reading passages.
- Optional **reading ruler** line highlight in `ReadingPassage`.

## Modes (ThemeProvider)

| Flag / API | Effect |
|------------|--------|
| `data-color-scheme="dark"` | Night-sky surfaces, light ink, adjusted soft tints (see **Foundations → Dark theme**) |
| `setColorScheme('light' \| 'dark' \| 'system')` | User or app appearance; **`system`** follows `prefers-color-scheme` |
| `data-high-contrast="true"` | Light: white surfaces + black ink. Dark: black surfaces + white ink |
| `data-reduced-motion="true"` | Shorter transitions; confetti → static star; no shake/sparkle flourishes |
| `data-parent-mode="true"` | Denser parent/teacher typography; mono-friendly data slots |

Storybook includes an **Accessibility toolbar** (appearance + a11y toggles). The provider honors **`prefers-reduced-motion`** and **`prefers-color-scheme`** when using **`system`** appearance.
